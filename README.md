# RUL-for-NASA-Turbofan-engines
A project to predict the remaining useful life (RUL )of engines.
The dataset used is from Kaggle: https://www.kaggle.com/datasets/behrad3d/nasa-cmaps/data, consists of multi-variate time-series data from 21 sensors - Temperature, Pressure, Fan speeds, etc.
Approach:
1. Data cleaning
2. Feature selection
3. Handling initial noise
4. Modelling
5. Model performance
6. Results
7. MLOps integration to the project (future plan)
